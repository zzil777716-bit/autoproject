## 🚀 Core Trading Strategies

### 1. 🪙 Crypto Engine (Upbit / Bithumb)
- **Kojiro Daisunhwan 6-Stage Moving Average Cycle**:
  - Classifies market state into 6 sequential stages:
    - `Stage 1`: Perfect Bullish Alignment (10 EMA > 20 EMA > 50 SMA) -> **Aggressive Buy / Hold**
    - `Stage 2`: Uptrend Fatigue -> **Partial Take Profit Preparation**
    - `Stage 3 & 4`: Downtrend Reversal & Bear Market -> **Strict Cash / Zero Buy**
- **Qullamaggie VCP (Volatility Contraction Pattern)**:
  - Energy compression (5-day range < 10%) followed by explosive breakout on > 1.2x 20-day Volume SMA.
- **Adam Khoo 20 EMA Pullback Bounce**:
  - Buying high-probability bounces off the 20 EMA in verified Stage 1 macro uptrends.
- **Dynamic Portfolio Allocation**:
  - `BTC` (100% base weight), `ETH` (80%), `SOL` (40%), Altcoins (25%~30% reduced sizing).

### 2. 📈 Korean Equities Engine (Kiwoom REST / OpenAPI+)
- **Macro Squeeze & Orderbook Divergence**:
  - 15-min Bollinger Bandwidth Squeeze (< 1.8%) + 3-min Volume RVOL > 2.5x + VWAP support.
- **Strict Guardrails**:
  - 1-share testing units, max 3 trades per day, -1.5% daily stop killswitch, 30-min loss cooldown timer.

### 3. 📱 Telegram Dual-Direction Controller
- Real-time instant push notifications for every Entry, Partial Take Profit, and Hard Stop.
- Interactive smartphone commands via `@hong_auto_bot`:
  - `/status`, `/balance`, `/coin`, `/stock`, `/stop` (Emergency Killswitch).
